📚 What I Learned

This task helped me understand EDA in a hands-on way.
Here are the main things I learned:

🔹 1. How to analyze a dataset properly

I learned to check structure, data types, missing values, and summary statistics before doing anything else.

🔹 2. Understanding visualizations

Visuals like histograms, boxplots, and heatmaps made it easier to see patterns such as:

Outliers in fare

Skewness in age distribution

Relationships between variables

🔹 3. Correlation and feature relationships

The heatmap helped me understand which features are more related.
This is important to avoid issues like multicollinearity in ML.

🔹 4. Importance of cleaning and understanding data

I realized that EDA is the foundation for all machine learning tasks.
If the data is not understood properly, the model will not perform well.

Overall, this task improved my confidence in exploring datasets and drawing meaningful insights from them.
